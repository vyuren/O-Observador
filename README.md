## Como acessar o projeto
### Método 1
- https://vyuren.github.io/oObservador/ (Não consegui fazer funcionar online);

### Método 2
1. Na página do repositório, clique em "Code" e em seguida em "Download ZIP";
2. Extraia o arquivo baixado;
3. Abra o VS Code (tenha o Live Server instalado);
4. Com o repositório aberto no VS Code, abra frontend/html/index.html;
5. No canto inferior direito, clique em "Go Live", isso abrirá uma página em seu navegador padrão.
